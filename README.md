# リコール対象車両照会アプリ

自動車の車台番号を使って、リコール対象かどうかと改修状況を照会する1画面のWebアプリケーションです。

> [!IMPORTANT]
> 本アプリのデータはサンプルです。リコール届出情報は実在情報を参考にしていますが、車台番号、個別車両、改修状況は架空です。実際の車両情報の確認には使用できません。

---

## アプリケーション概要

ユーザーは次の2つの方法で車両を指定できます。

- 車種とサンプル車両を選択する
- 車台番号を直接入力する

車両を照会すると、次のいずれかを表示します。

| 判定 | 条件 |
|---|---|
| リコール対象・未改修あり | 未改修のリコールが1件以上ある |
| リコール対象・すべて改修済み | リコールがあり、すべて改修済みである |
| 登録車両・対象リコールなし | 車両は登録されているが、リコール情報がない |
| 該当車両なし | 車台番号に一致する車両が登録されていない |

詳細な仕様は[`PRD.md`](./PRD.md)を参照してください。

### 使い方

1. 「車種」から車種（シエンタ／クラウン／RAV4）を選ぶ
2. 「サンプル車両」から車両を選ぶと、車台番号が自動入力される
   - 車台番号を直接入力する場合は、1〜2を省略してよい
3. 「リコール情報を確認」ボタンを押す
4. 判定結果と、車両情報・リコールごとの改修状況が表示される

入力した車台番号は、前後の空白を除去し、英小文字を大文字に変換してから照会します。

### 動作確認に使える車台番号

`data/vehicles.json`のサンプルデータに対応しています。

| 車台番号 | サンプル車両 | 期待される判定 |
|---|---|---|
| `MXPL10-9900001` | シエンタ サンプル車両001 | リコール対象・未改修あり |
| `AXAP64-9900004` | RAV4 サンプル車両001 | リコール対象・未改修あり |
| `MXPL10-9900002` | シエンタ サンプル車両002 | リコール対象・すべて改修済み |
| `AZSH32-9900003` | クラウン サンプル車両001 | リコール対象・すべて改修済み |
| `MXPC10-9900005` | シエンタ サンプル車両003 | 登録車両・対象リコールなし |
| `MXPL10-9999999` | （未登録） | 該当車両なし |
| `  mxpl10-9900001  ` | （正規化の確認） | リコール対象・未改修あり |
| （空欄） | — | 入力エラー |
| `MXPL109900001` | （ハイフンなし） | 入力エラー |

## E2Eテストで確認する主要シナリオ

| No. | シナリオ | 期待結果 |
|---|---|---|
| 1 | 車種とサンプル車両を選択する | 対応する車台番号が自動入力される |
| 2 | 未改修車両を照会する | 「リコール対象・未改修あり」と表示される |
| 3 | 改修済み車両を照会する | 「リコール対象・すべて改修済み」と表示される |
| 4 | リコール情報のない登録車両を照会する | 「登録車両・対象リコールなし」と表示される |
| 5 | 未登録の車台番号を照会する | 「該当車両なし」と表示される |
| 6 | 車台番号が未入力のまま照会する | 入力エラーが表示される |
| 7 | 不正形式の車台番号を入力する | 入力エラーが表示される |
| 8 | 小文字と前後空白を含む車台番号を入力する | 入力が正規化され、該当車両を照会できる |

## サンプルデータ

`data/vehicles.json`には、次の確認に必要なサンプルデータが含まれています。

- 未改修のリコールがある車両
- すべて改修済みの車両
- 対象リコールがない登録車両
- 複数の車種

未登録車両の確認では、JSONに存在しない形式上有効な車台番号を使用します。

サンプルデータを変更した場合は、PRD、画面表示、E2Eテストの期待値に影響がないか確認してください。

## 開発ルール

- `PRD.md`を要求の正とする
- 実装前に計画を提示し、人間が確認する
- 業務用語は`docs/glossary.md`に従う
- 技術構成は採用済みADRに従う
- PRDにない機能を独断で追加しない
- 実装後は人間による手動確認を行う
- E2Eテストの観点を人間がレビューする
- テスト失敗時は、実装とテストのどちらが原因か切り分ける
- 修正後は関連テストだけでなく、E2Eテスト全体を再実行する
- READMEには実際に確認できた手順だけを記載する
- 実在する個別車両の情報を追加しない

詳細なClaude Code向けルールは[`CLAUDE.md`](./CLAUDE.md)を参照してください。

---

## 対象外

本アプリでは、次の内容を扱いません。

- ログイン・認証
- データベース
- 外部API連携
- 車両データの登録・更新・削除
- 改修状況の更新
- 実在する個別車両の検索
- VINおよび車台番号の完全な規格チェック
- 本番運用向けのセキュリティ・監査・可用性設計
- GitHub ActionsによるCI/CD
