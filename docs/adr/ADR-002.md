# ADR-002：3D車両ビューの実装方法と3Dモデルの選定・配布方法

## ステータス

採用

## 日付

2026-11-27

## 背景

照会結果を文字だけで表示すると、「車のどこに不具合があるのか」が伝わりにくい。ハンズオンの成果物としても印象に残りにくい。そこで、照会結果に3D車両モデルを表示し、リコールの不具合部位を強調することにした（PRD 5.8）。

決める必要があったのは次の3点である。

1. 3Dをどう描画するか
2. 車両の3Dモデルをどう用意するか
3. 3Dモデルをどう配布するか

このリポジトリはGitHubで公開（PUBLIC）されている。gitに含めたファイルは、誰でも取得できる状態になる。

## 決定

### 1. 描画にはthree.jsを使う

- 追加する依存は `three` の1つだけにする。React向けのラッパー（`@react-three/fiber` など）は使わない。
- 3D表示の処理は1つのコンポーネントに閉じ込め、他の画面部品はこれまでどおりシンプルな構成のままにする。

### 2. 既製のglTFモデル（.glb）を読み込む

- 既定のモデルは、Khronos Groupが公開している **Car Concept**（CC-BY 4.0）とする。
- 任意のモデルとして、**RAV4風モデル**（GitHubの `jnibarger01/toyota-showroom` の `assets/imported/toyota-rav4-showroom.glb`）を使えるようにする。
- 部位の強調は、モデル内のパーツ名で対象を特定して行う。部位とパーツの対応はPRD 5.8に定める。

### 3. 配布方法はモデルごとに分ける

| モデル | gitへの同梱 | 理由 |
|---|---|---|
| Car Concept | する（`public/models/car-concept.glb`） | CC-BY 4.0で再配布が許可されている。クレジットを表示すれば公開リポジトリに置ける |
| RAV4風モデル | しない（`public/models/rav4.glb` を `.gitignore` に登録） | ライセンス表記がない。法的には無断で再配布できない扱いになる |

- `public/models/rav4.glb` が存在すればRAV4風モデルを、存在しなければCar Conceptを表示する。
- RAV4風モデルは参加者が当日に任意で取得する。取得コマンドはREADMEに記載する。
- Car ConceptのKhronos Groupのロゴは表示しない（パーツの非表示とタイヤ側面のテクスチャ除去。詳細はPRD 5.8）。ロゴは許諾の対象外のため。
- クレジットは「Car Concept by Eric Chadwick, © 2024 Darmstadt Graphics Group GmbH (CC-BY 4.0)」とする（Khronosリポジトリの `metadata.json` に基づく）。

## 検討した選択肢

### 描画方法

| 選択肢 | 判断 | 理由 |
|---|---|---|
| SVGの2D車体図 | 不採用 | 実装は簡単だが、「感動できるアプリにしたい」という目的に対して表現力が足りない |
| three.js | **採用** | 依存1つで、モデルの読み込み、半透明化、カメラ移動まで実現できる |
| three.js＋React Three Fiber | 不採用 | Reactらしく書けるが、依存と学ぶ概念が増える。初心者向けハンズオンの方針に合わない |

### 3Dモデルの入手方法

| 選択肢 | 判断 | 理由 |
|---|---|---|
| three.jsの基本図形でコードから組み立てる | 不採用 | 試作したが、おもちゃのような見た目にしかならず、リアルさの要望を満たせない |
| Car Concept（CC-BY 4.0） | **採用（既定）** | 見た目の品質が高く、パーツに論理的な名前が付いている。ライセンスも明確 |
| RAV4風モデル（ライセンス表記なし） | **採用（任意・同梱しない）** | 日本車らしく、データの車種（RAV4）とも一致する。ただしライセンスが不明なので同梱しない |
| 有料マーケットの実車モデル | 不採用 | 「報道・解説用途に限る」ライセンスが多く、アプリに組み込めない |
| CC0のローポリ車両（Kenneyなど） | 不採用 | 権利は安全だが、見た目がおもちゃ寄りで要望と逆方向 |
| トヨタの正規3Dデータ | 保留 | 最も望ましいが、入手できるかは未確認。入手できれば `public/models/` のファイルを差し替えるだけで対応できる |

## 結果

### 良くなること

- 照会と同時に不具合部位が光るため、リコール内容を直感的に把握できる。
- 公開リポジトリには、ライセンスが明確なファイルだけが含まれる。
- RAV4風モデルがなくても、アプリはCar Conceptで動作する。

### 受け入れること

- 全車種で同じ3Dモデルを表示する。シエンタやクラウンを照会しても、形状は実車と一致しない（PRD 4章に明記）。
- どちらのモデルにもシートベルト単体のパーツがないため、座席全体の強調で代用する。
- リポジトリのサイズが約11MB増える。
- canvas内の描画はE2Eテストで検証しにくい。テストは「注目部位」の文字表示で行う（PRD 9章）。
- RAV4風モデルの利用は社内ハンズオンの範囲にとどめる。スクリーンショットや資料を外部に公開する場合は、Car Conceptで表示する。
